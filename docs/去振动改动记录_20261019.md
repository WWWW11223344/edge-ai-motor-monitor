**日期**：2026-10-19  
**起因**：确定以「电流」为唯一监控变量后，振动不再是实验变量。

## 二、顺带停用了板上 19 维 AI（必须做）

**为什么绕不开**：19 维特征里 [5..15] 这 11 维全部来自加速度计，
去掉 MPU6050 就没法算出这 11 维。而 `ai_monitor_feed_frame()` 的第一道门禁是

```c
if ((frame->level != 1) || (frame->duty != 58) ||
    (frame->validMask != M2_VALID_ALL)) {   /* M2_VALID_ALL = 0x3F */
    reset_window();      /* 清空窗口 */
    ...
    return;
}
```

去掉三路加速度后，`validMask` 最多只有 `电流|转速|电压` = **0x31**，
`!= 0x3F` 恒成立 → 每帧都 `reset_window()` → `g_learned` 永远到不了 22。

**后果**：`ai_monitor_init()` 会把阶段置成 `AI_MONITOR_LEARNING`，而它再也走不到 DET，
屏幕底条就会永远显示 **LRN**，看起来像死机。

**处理**：在 `main.c` 里把 `ai_monitor_init();` 整行注释掉（原地留了解释注释）。
这样 `g_phase` 保持初值 `AI_MONITOR_OFF`，底条显示 **SIM**（纯采集模式），行为干净。

`feature19.c` / `ai_monitor.c` 一行未改，只是没人调用，链接器已把它们的段剥掉。

## 四、屏幕现在长什么样

```
页 0~1   Spd  xxxxx  rpm        <- 转速（大字号）
页 2~3   Cur  x.xx   A          <- 电流（大字号）
页 4~5   （空白）                <- 原振动行，留给后续电流波形信息
页 6     Bat xx.xV  ST:XXXXX    <- 母线电压 + 状态（小字号）
页 7     SIM  L1:58%  T xxxxxxs |  <- 模式 + 档位 + 运行秒数 + 心跳
```

底条左侧固定显示 **SIM**（因为 `AI_MONITOR_OFF`），不再出现 LRN / DET。

## 五、对外部的影响

| 对象 | 影响 |
|---|---|
| D1 mini（`status_json.cpp`） | **不用改**。它按 bit 判 `validMask`，位为 0 时该字段输出 `null`，不拒帧 |
| M2 帧格式 | **不用改**。仍是 42 字节，`value[1..3]` 只是不再写入，对应有效位恒为 0 |
| 波形采集脚本 `wave_capture.py` | **不用改**。走的是 USART1 的 418 字节波形帧，与振动无关 |
| `ai_samples` 里已有的历史数据 | 不受影响，但新采的会话将不再有加速度列有效值 |

## 七、恢复路线 C（1 轴 × 200 点电流模型）时要改什么

1. `main.c` 把 `/* ai_monitor_init(); */` 的注释去掉；
2. 换掉 `ai_monitor.c` 里喂给模型的数据源 —— 由 `feature19_get()` 的 19 维
   改为 `fastcap_get_last_block()` 的 200 点原始码（`nanoedge_1axis200` 那套输入）；
3. 门禁条件里的 `M2_VALID_ALL` 改成「电流 + 转速 + 电压」的新宏，
   不再要求加速度位；
4. 用 Studio 新生成的库替换 `ai_monitor` 里的现有库。

在此之前，板上 AI 保持停用，采集与遥测不受影响。
